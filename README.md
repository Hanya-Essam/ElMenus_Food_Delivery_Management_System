# ElMenus Food Delivery Management System

**ElMenus** is a C++ food delivery management system developed as a team project.

The system is designed to manage the main operations of a food delivery service, including customers, delivery drivers, orders, and order statuses.

## Project Features

* Customer management
* Delivery driver management
* Order management
* Order status tracking
* Customer and driver information handling
* Dynamic management of customers, drivers, and orders

## Technologies

* **C++**
* **Object-Oriented Programming (OOP)**
* Arrays and dynamic memory management
